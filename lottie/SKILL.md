# Lottie / Telegram-стикеры кодом

Всё генерится Python-скриптом поверх исходного JSON. Оригиналы не трогать — результат в отдельную папку.
Инструменты лежат в `scripts/` рядом с этим файлом (дальше `$L`).

## Ограничения Telegram (.tgs) — проверяются `check()` при сохранении
- .tgs = gzip от Lottie JSON. 512×512, 60 fps, ≤ 180 кадров (3 с), **≤ 64 КБ после gzip**.
- Нельзя: expressions, маски, track matte, картинки, эффекты слоёв, 3D-слои. Null-слои (ty 3), градиенты, trim paths — можно.
- Цикл должен быть бесшовным: кадр 179 → 0 без скачка.
- rlottie (движок Telegram) рисует чуть иначе, чем lottie-web. Всё, что проверено только в браузере, помечать `[НЕПРОВЕРЕНО]` и просить пользователя закинуть файл себе в «Избранное».

## Рабочая папка
```bash
cd <workdir> && python $L/unpack.py path/*.tgs      # -> tgs/<name>.json, out/, sheets/, iso/
python $L/srv.py                                  # фоном: http://127.0.0.1:8766 (статик + приём PNG)
PYTHONPATH=$L PYTHONIOENCODING=utf-8 python make_x.py "<папка вывода>"
```
Скрипт стикера: `from lot import *` + `from lot7 import *` (и `from lot7 import _mono_interp`, если нужен). Примеры — `scripts/examples/`.

## Пайплайн (порядок важен)
1. **Разведка.** `python $L/groups.py <name> <префикс слоя>` — группы с bbox и цветами; `python $L/iso.py <name>` — каждый слой в отдельный json → лист через sheet.html; кадр 512 + `grid.py` — сетка координат, чтобы найти шею, локти, запястья, щель зубов. Имена слоёв AE часто на русском (`скелет`, `кепарь`, `рука`), а части тела сидят в чужих слоях (полоски штанов в слое кепки) — проверять изоляцией.
2. **Риг.** Null `RIG` (общий масштаб/отскок) → null `HEAD` с якорем **в основании шеи** → слои головы детьми. Слой из многих частей резать `split_layer` (кости: плечо → предплечье → кисть; палец → фаланги). `C.pivot(L, точка, r=…, s=…)` переносит якорь без сдвига картинки.
3. **Движение — только пружинами.** `spring([(t, цель)…], f, z, idle=wave(...))` → плотные сэмплы → `lin(...)`. Позы задаются целями, пружина сама даёт разгон, перелёт, затухание. Периодика — `wave(amp, cycles)` (целое число циклов на 180 кадров = бесшовно). Наложение/отставание: кепка, пальцы, волосы — та же цель, ниже `f`, со сдвигом.
4. **Деформации контура** — через один `Deformer`: `D.add(groups, keys, factory)` на каждый канал (глаза-дуги, веки, рот, поворот головы, бурление), в конце один `D.build()`. Никогда не звать `morph_groups` дважды на одну группу — второй затрёт первый.
5. **Фейк-3D поворот головы**: `turn_fn(HC, R, 'surface', 1.0)` с позами `YP=[(t,(yaw,pitch))]`, 3–10 поз за цикл. **Одно поле на всю голову** (череп, челюсть, черты, кепка, наушники — один центр и радиус), иначе черты вылезают за контур. Задник кепки — `'back'`. Мелкие добавленные элементы (веки, язык) двигать `gtr(g)['p']` = смещение точки тем же `tf`.
6. **Свет** — после `D.build()`: `shade_world(C, (слои…), YP, head['ind'])`. Cel-shading: жёсткий полумесяц тени + рефлекс по краю + маленький блик только на глянце. Свет зафиксирован в мире (компенсирует повороты всех родителей и групп). Белые кости — тень цвета рисунка `(0.71, 0.82, 0.85)`.
7. **FX**: `sparkle`, `puff`, `comet` (сужающийся шлейф вместо линий), `glow` (радиальный градиент), слёзы — баллистика хвостиком назад. Всё, что вылетает за 180 кадр, дублировать `wrap_copies`/`loop_copies`.
8. **Сохранение**: `C.save(name, outdir)` — печатает размер и `OK/FAIL` по ограничениям.

## Проверка — всегда своим прогоном, не на глаз по коду
- Раскадровка: `http://127.0.0.1:8766/sheet.html?files=out/x.json&fr=0,30,60&s=256&cols=4&out=x.png` → `sheets/x.png` → смотреть Read'ом. Крайние позы поворота и моменты контакта — крупно (`s=400–512`).
- Шов: `fr=176,179,0,3`.
- Рывки: `python $L/jerk.py <name>` — топ свойств по скачку скорости. Пики на моргании — норма; всё остальное > ~8 разбирать.
- Размер: если > 64 КБ — `D.build(step=15)` (реже сэмплы морфа), меньше групп под светом, меньше частиц. Морфинг — главный потребитель веса.
- Итог пользователю: `preview.html` со всеми стикерами + раскадровки через SendUserFile.

## Грабли (каждая уже стоила итерации)
| Симптом | Причина | Как правильно |
|---|---|---|
| Дёргано, «ускорено в 5 раз» | короткие ключи 2–5 кадров, тряска через 3–4 кадра | пружины; тряска с периодом 11–16 кадров, затухающая |
| Спотыкается на каждом ключе | ease-in/out на каждом ключе, ключи разных каналов слиты | `_mono_interp` между позами, выход `'lin'` |
| Голова крутится не от шеи | якорь «на глаз» | якорь по сетке в основании шеи; подбородок, лежащий на руке, — руку двигать за подбородком |
| Складка и её тень расходятся | разные фазы у пары линия+тень | одна фаза на пару |
| Линии вылезают за контур при повороте | разные формулы/радиусы для частей головы | одно поле `surface` на всю голову |
| Плоско | двигаются плоские куски | морф контура + фейк-3D позы + желе тела 2–4 % |
| Руки «как листы А4» | изгиб контура кисти | кисть жёсткая, поворот 3D (`turn_fn` на ладони) |
| Тень «сама по себе» | свет в локальных координатах детали | `shade_world` |
| Аэрограф-пятна | мягкий радиальный градиент на каждую деталь | cel с жёсткой границей, общий свет, цвет тени из рисунка |
| Круги-«наклейки» | блик на ткани | блик только на глянце, маленький |
| Непонятные пятна | падающие тени кружками | не делать; если нужно — анимировать вместе с источником |
| Палец/фаланга двигается без руки | анимирован только палец | движение от запястья, палец — акцент |
| Скрываются все фаланги | масштаб всех сегментов | складывать только 2 верхние, при ~0 — прозрачность |
| Язык снизу поверх зубов | точка роста на подбородке | из щели между зубами + следовать повороту головы |
| Рот «открывается, но не открывается» | сдвиг челюсти без рта | `mouth_rig` (верхние зубы сжимаются, тёмный рот, язык, нижние зубы) или вообще не трогать челюсть |
| «Много эмоций» | 3–4 эмоции в 3 с | одна эмоция на стикер |
| Монета плоская | масштаб по X | ребро с насечками + затемнение лица в профиль; насечки тонкие |
| Хвост анимации рвётся на стыке | частица живёт после 180 | `wrap_copies` |
| Кэш браузера показывает старое | lottie json из кэша | sheet.html уже с `no-store` |
| Правка скрипта «не применилась» | индексы групп сдвинулись после вставки | искать группы по ссылке/содержимому, не по номеру |

## Работа с пользователем
- Сначала контрольная точка: 1–2 стикера, показать, получить «ок», потом остальные.
- Отчёт: таблица «замечание → причина → что сделано», размеры, что не проверено.
- Разбор чужих референсов: мерить, а не смотреть — сколько морфов, шаг ключей, смещение черт между позами (центроид/масштаб по ключам). В хороших стикерах: 30–100 морфящихся контуров, ключи раз в 7–22 кадра, черты сдвигаются неравномерно (ближние сильнее — это и есть 3D).

## Карта библиотеки
- `lot.py`: `anim/st/lin/tr/lks`, `fill/stroke/gfill/ellipse/rect/trim/group/shape/path`, `Comp` (`load/null/layer/insert/pivot/save`), `split_layer`, `gxf` (анимация группы вокруг точки), `morph_groups`, `deform`, `bend_fn`, `turn_fn`, `Deformer`, `mouth_rig`, `spring/wave/sampled/add`, FX (`sparkle/puff/comet/glow/drop_path/star_path`), `wrap_copies/loop_copies`, `check`.
- `lot7.py`: `_mono_interp`, плавный `Deformer.build(step)`, вычисление трансформов (`prop_at`, матрицы), `shade_world` / `cel3_group`.
- Примеры: `examples/finger_rig_3d_light.py` (кости пальца, веки, язык, 3D, свет), `examples/laugh_mouth_hands.py` (смех: рот, жёсткие 3D-кисти, слёзы), `examples/enhance_existing_stars.py` (доработка чужой анимации без переделки).
